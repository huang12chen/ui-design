# 面向不同应用设计

[English](../application-design.md)

先看使用者要做什么决定。下面列的是任务和检查方式，不是固定风格或页面模板。已有品牌、研究、内容及用户要求优先。

| 应用 | 关键问题 | 可以探索的结构 | 状态与验证 |
| --- | --- | --- | --- |
| 品牌或服务 | 提供什么、面向谁、凭什么可信？ | 编辑式叙事、产品演示、活动、目录或精简服务介绍 | 导航和 CTA 到达承诺的位置；手机上的媒体和文字可读；不捏造客户或背书 |
| 商城 | 访客能否识别、比较、选择商品并理解费用？ | 搜索目录、精选集合、商品详情或引导比较 | 规格选择、无货、购物车数量与合计、空车、移除及真实结账；演示不能伪装成支付 |
| 后台或运营 | 现在要判断或处理什么，依据是什么？ | 表格与详情、总览到明细、状态看板、时间线或地图 | 时间、单位、筛选、图表和记录使用同一数据；检查空结果、加载错误、键盘及窄屏表格 |
| AI 产品 | 系统能做什么、会使用哪些信息、用户如何查看和修改结果？ | 上下文编辑器、对话、审核队列、结构化生成或混合流程 | 可编辑示例、输入校验、当前结果、实际支持的进度/取消、失败重试、过期结果与导出一致；区分模板、模拟和真实模型 |
| 作品集 | 这个人做了什么，读者能查看什么依据？ | 精选索引、连续叙事、详细案例、档案或其他适合材料的形式 | 贡献、来源和结果真实；作品直接可达，检查手机媒体、案例返回、联系和隐私 |

## 推导视觉系统

写清主要任务、信息对象与第一个有效操作，再决定层级和密度：比较订单的表格，与品牌活动图或可编辑文档有不同约束。定义颜色角色、字号角色、间距、网格、表面和控件形状，记录具体值及其理由。用真实最长文案、混合文字、数据单位检查排版、对比度、焦点和图像比例。不要复制参考的品牌身份或标志性构图。

比较方向时一起看导航模型、首屏、密度、节奏、字体、媒体、表面与交互。同一产品家族可以有意共用设计系统；不同产品不应因惯性变成同一个样子。只换配色或职业不能证明差异。

需求开放、确有探索空间时，先构思至少两种合理的**结构**：首屏出现什么、用户先操作什么、内容如何分组、什么视觉材料承载概念。例如同一家商店可以以商品集合、单一产品叙事或引导比较为主，各自对应不同决策路径。根据实际任务和品牌选择，而不是为了新奇而变化；已有设计系统或明确方向时不必强行探索。对照近期作品：反复出现的左右首屏、相同标题句式、装饰符号、字体搭配、卡片形状和动效，即便换色也会形成固定个人风格。不适合当前需求时改变底层选择；有助于使用时保留熟悉模式。

## 把方向落实到页面

开放需求先明确用户要做的决定、第一步、真实内容和信任依据。用几行比较两种信息结构：首屏内容、导航、内容分组与手机流程；选择最符合受众与任务的一种，并在 DESIGN.md 写下取舍。若需求已经指定品牌或布局，遵循已有方向，只处理真正缺失的信息。

根据选定结构和实际素材确定视觉与动效：说明什么移动、由什么触发、改变什么状态，以及减少动效时如何使用。至少做出一个与具体内容相关的视觉或交互选择，不要只换配色。在桌面和手机查看首屏及主要任务；若重复构图、层级薄弱或通用装饰与需求不符，就修改。高频工作流程不必为了新奇牺牲熟悉性。

## 按目的选择交互

| 模式 | 适用时机 | 实现与检查 |
| --- | --- | --- |
| 原位展开或抽屉 | 查看或编辑时需要保留上下文 | 入口容易找到；提供明确关闭、Escape、焦点恢复和合适的滚动；检查长内容和触屏 |
| 筛选与图表联动 | 需要在同一范围比较指标和记录 | 一个状态驱动标签、合计、图表和记录；标明周期与单位；检查快速切换、空结果及不用悬停的查看方式 |
| 建议提示 | 开放输入需要起步示例 | 填入可编辑内容或明确启动操作；保留用户修改并说明结果来源和限制 |
| 前后对比滑块 | 比较前后差异有意义 | 用可访问的范围控件和对齐的图像尺寸；检查键盘、触屏、标签与两端 |
| 共享转场 | 从列表到详情需要保持连续感 | 没有转场时路由和返回仍可用；避免重复内容、移动点击区和缺失减少动效替代 |
| 拖拽、长按或手势 | 直接操作确实有助于任务 | 提供可见按钮、输入或键盘路径；允许取消并保持状态，不让手势成为唯一入口 |
| 材质、景深、玻璃、3D 或环境动效 | 有助于品牌表达或解释真实对象和关系 | 控制加载与动效成本，保证变化背景上的文字可读，提供静态替代，检查手机、低性能与减少动效 |

有动画不等于有反馈。检查触发动作、前后状态、结果是否真实，以及重复、打断、失败和取消时发生什么。视觉按压不等于硬件触觉。文本输入使用组合事件，输入法选字期间不提交；针对实际浏览器和语言测试，不把选字后固定延时当通用规则。

## 原型边界与测试

在读者遇到虚构品牌、示例数据和本地模板结果的位置明确标注，不捏造支付、后台更新或模型回复。影响结果的输入改变后，应重新生成或明确标记旧结果已过期，避免导出误导性内容。图表、摘要和表格应基于同一筛选数据。

桌面和手机都要操作实际主路径及相关失败恢复路径，并检查键盘和触屏替代。查看运动中间状态和覆盖层，不只看最终帧。视觉验收与自动检查分别记录：两者能发现的问题不同。
