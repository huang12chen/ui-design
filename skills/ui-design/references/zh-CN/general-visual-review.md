# 面向实际需求的视觉方向与验收

[English](../general-visual-review.md)

本指南适用于不同类型的网站和产品。好的结果让目标任务容易理解，呈现适合受众的气质，并把细节执行到位。没有一套固定的配色、字体、版式、留白、密度或动效，能让所有界面都显得高级。

## 先决定这个项目需要什么

1. 写清使用者是谁、眼前要完成什么、需要理解或判断什么，以及下一步真实操作。已有产品先检查当前流程和已有设计系统。
2. 使用已提供的品牌、内容、无障碍要求、语言、设备、技术约束和用户明确偏好。假设要标为假设；无法从现有信息解决且会改变结果的问题再询问，否则先提出可调整的方向并继续。
3. 把希望传达的气质写成能指导选择的词，例如可靠精确、亲切有活力、克制而富有编辑感，并说明它为何适合当前受众和任务。严肃的金融工具和活泼的金融教育网站都可以有审美；行业名称本身不能决定风格。
4. 一起选择信息层级、导航、密度、字体、图像、颜色角色、表面、控件和动效，说明主要取舍。用真实内容、状态和设备检验，而不是只做一张气氛图。
5. 需求开放或方向会显著影响结果时，可以比较几个可行方向再选择或呈现；用户已经明确风格或有现成设计系统时优先遵循，不为制造差异而差异。同一产品家族可以有意保持一致。

例子只用于说明思路：同样是预约服务，面对第一次使用且比较焦虑的人，可以用清楚、平和的分步流程；面对熟悉业务的排班人员，可以用紧凑、高密度的日程。区别应体现在任务与交互中，也体现在视觉表达中。反过来，两个不同品牌在都需要比较数据时，也可能适合使用相似表格。

## 查看实际渲染结果

在相关的桌面与手机宽度下，尽可能使用获准的真实内容检查。记录浏览器、尺寸、实际操作及未验证范围。截图或自动检查本身都不能证明视觉效果合格。

| 要判断什么 | 看什么证据 |
| --- | --- |
| 是否适合目的和使用者 | 读者能理解服务或当前任务，找到重点和下一步；没有捏造资历、客户或数据。 |
| 气质是否连贯 | 字体、图像、颜色、密度、版式和交互是否共同服务需求；尊重已有品牌约束，例外有理由。 |
| 层级是否有用 | 标题、分组和强调是否支持任务。密集比较可以有多个重要区域，品牌活动也可以突出单张图像；都不是强制公式。 |
| 细节是否到位 | 检查实际绘制字体与语言覆盖、换行、对齐、间距、裁切、图标线重、边框和表面边缘；找出意外不一致、遮挡、缺失内容与对比不足。留白应服务分组和阅读，并非越多越高级。 |
| 能否顺利使用 | 操作真实主路径、导航和相关的空、错误、恢复、输入变更状态；按需检查焦点、键盘、触屏、响应式和减少动效。 |
| 动效是否有价值 | 没有动画时变化仍可理解；时机、性能和视觉效果适合场景。静态反馈也可能是正确选择。 |

用真实长短文案、混合语言和合理数据检查；在构图发生变化的中间宽度查看，而不是只看设备预设。提出视觉问题时说明看到了什么、为什么影响当前需求；不要因为页面没有规定的首屏、阴影、圆角、标题行数或装饰动效就判定好坏。

## 如何看旧检查结果

旧版作品集案例和自检器包含有价值的观察，也包含作品集场景形成的规则。它们是可选工具，不是通用审美评分。工具发现值得逐项检查：确认属于无障碍、功能或渲染问题就修复；规则不适合当前项目时说明原因，不强行改成工具喜欢的样子。检查通过不能证明视觉方向正确，未测量也不能算通过。报告结果时保留工具原有退出码和证据。
