# 交互与动效

根据需求选择动效，不设统一风格。时尚发布可以有戏剧性，调度工具可能更需要快速、易读的反馈，轻松的产品也可以鼓励探索。氛围、愉悦感与品牌个性都是正当目标，和方向感、操作反馈一样有价值。动效强度应符合用户意图、已有品牌和真实内容；不要把用户明确要求的动效换成静态页面或只有鼠标悬停才出现的装饰。

下表是可组合、可改造的技术，不是必须全部使用的清单。需要丰富表现时可以编排多个效果；必须实际实现并检查手势、状态和视觉，而不是只写出某个库的名字。

| 技术与适用场景 | 构造与状态 | 验证 |
| --- | --- | --- |
| 图标变化、按压与释放：控件、反馈、导航 | 根据真实状态改变 transform、透明度或可插值 SVG；无障碍名称和 pressed/expanded 状态保持一致。设计静止、焦点、按下、停用和回弹。 | 键盘和触屏、连续点击、取消、最终状态与减少动效。 |
| 空间层次、粘性叙事与滚动视差：活动、作品集、编辑内容 | 确有叙事需要时让图层随滚动差速移动；保留可读内容与普通布局回退。检测滚动时间线支持；手机上调整或取消会遮挡文字的独立位移。 | 在手机、中间宽度、桌面完整滚动并检查移动图层是否盖住文字；慢速滚动、关闭动效及不支持时间线的浏览器仍要可读。 |
| 共享元素、卡片到详情：内容集、商品详情、媒体 | 根据前后几何关系制作过渡，或渐进增强使用 View Transition API。动画跳过时仍更新真实页面；原焦点消失时正确安置焦点。 | 进入与返回、快速连续操作、键盘、不支持浏览器及减少动效；检查文字拉伸和重复过渡名称。 |
| 倾斜、跟随光斑、发光边缘：有触感的品牌或商品界面 | 保持点击区域稳定，移动内部装饰层；限制指针坐标，离开或取消时复位，触屏和键盘提供静态效果。 | 指针进入/离开、快速移动、焦点、触屏、对比度和小屏；高光不得遮住文字。 |
| 玻璃、环境色和立体场景：品牌氛围、沉浸体验 | 半透明层提供经过检查的不透明回退；仅在适用且有许可时从真实素材取色。WebGL/3D 要有实际场景、按需加载和回退，并在离屏或页面隐藏时停止不必要工作。 | 变化背景上的对比度、减少动效、不支持效果、设备性能和素材或 WebGL 缺失。没有使用 3D 引擎或实时数据时不要暗示已经使用。 |
| 拖动、长按、滑动、径向操作、前后对比：直接操控 | 明确开始、移动、提交和取消状态；合适时使用指针捕获，处理 `pointercancel` 并保留页面滚动。提供可见按钮或键盘替代；长按不能悄悄触发无关操作。 | 触屏、鼠标、键盘、中断、范围外释放、连续操作和恢复。 |
| 排序、卡片展开与数据过渡：看板、筛选、图表 | 测量前后位置或使用布局过渡；排序、图表、标签和合计必须来自同一真实状态，动画不能延迟正确数据或虚构进度。 | 快速切换、空状态、动画中断、最终数字、减少动效及显示数据一致性。 |
| 抽屉与对话框：导航、集中任务 | 设计明确的打开/关闭状态和即时回退；保留对话框语义、焦点进入和返回、Escape 与滚动。 | 鼠标、触屏和键盘开关，中途取消、焦点返回及超出视口的长内容。 |

## 从想法到可操作的过程

- **滚动**：区分跨过阈值后播放一次的入场，和进度始终跟随滚动的场景。后者先定义起止几何位置、各层速度；支持时可用命名 view timeline，必要时使用有边界的测量回退。文字和点击区域不要跟随装饰层移动；双向完整滚动，检查中间画面。
- **直接操控**：保留按下位置与元素的相对偏移，从实际边界计算位置，明确松手后提交、吸附还是回弹取消。需要惯性时估算最近一段速度，并让回弹从合适的初速度接续；不要把某个固定阈值套给所有控件。处理指针捕获丢失、操作中断和触屏滚动。前后对比可以直接使用支持键盘和触屏的 range 控件，无须自造拖拽物理。
- **变形与连续性**：先识别两种状态中延续的是哪个对象，再测量起点和终点；动画失败时真实 DOM 仍需更新。连续操作可以中断或重新指向动画；详情仍需要可访问的关闭/返回及正确焦点。视觉平滑不能代替真实功能。
- **材质与氛围**：根据视觉方向决定运动层、光源、纵深和色彩，先准备不透明、静止的状态；使用封面取色或 WebGL 时确认来源和实际可用性。用明暗不同的素材和较慢设备检查；当需求明确追求表现力时，模糊、变色或 3D 场景本身可以是重点。
- **编排**：把用户动作、状态变化、视觉反馈和完成结果放进同一时间线。高频控件保持即时，根据距离和情境调整时长；重复输入时允许停止或改向。加载与进度必须对应真实工作，不要为了展示动画而虚构等待。

根据 `prefers-reduced-motion` 调整编排，重要内容和操作在不运动时仍可使用。提供动效开关时，标签和实际行为要一致，包含系统初始偏好及后续变化；用户暂停后不要强制恢复。检查真实画面和交互，不能只看静态截图或 DOM 检查。模拟功能要如实标注；使用第三方代码或素材前核对许可并保留所需署名。

实现细节和兼容性可查阅 [View Transition API](https://developer.mozilla.org/en-US/docs/Web/API/Document/startViewTransition)、[滚动驱动时间线](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Scroll-driven_animations/Timelines)和[指针捕获](https://developer.mozilla.org/en-US/docs/Web/API/Element/setPointerCapture)的当前文档。列出一种技术不表示已经看过每个来源的实现或原视频。
